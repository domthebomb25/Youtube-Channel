## Long video upload checklist (Day 0)

- ☐ Title (< 60 characters, company name + key hook)
- ☐ Thumbnail (≤ 4 big words, readable on a phone) — use Test & compare if offered
- ☐ Description with chapters + sources + subscribe link
- ☐ Tags
- ☐ Captions (.srt) uploaded
- ☐ Pinned comment (a question to get replies)
- ☐ End screen (next/best video + subscribe)
- ☐ Mid-roll ads on (if over 8:00)

## Every day
