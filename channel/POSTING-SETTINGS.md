# Posting settings checklist (use every time)

Channel: **The Business Stick HQ** · handle @TheBusinessStickHQ / thebusinessstickhq on every app.
Content = AI-generated cartoon images + AI narrator voice (Benji). Upload the original file, never a re-download.

## TikTok
- Upload → Next → **no music / text / filters** → Next
- Caption + hashtags (incl. #businesstok)
- Cover: frame with the title text clear
- Who can watch: **Everyone** · Comments: **On** · Duet/Stitch (reuse): **On**
- **AI-generated content: ON** (realistic AI voice)
- **Identify similar products: OFF** (no TikTok Shop tags)
- Visual search: **On**
- **Series (Parts):** Profile → ⋯ on the video → Add to playlist → one playlist per series (e.g. "Costco $1.50 Hot Dog"), Parts in order. If playlists aren't unlocked: comment on the previous Part "Part N is up on my page 👉"; after the series, pin intro + Part 1 + Part 2.

## Instagram Reels
- + → REEL → **no music / text / stickers / filters**
- Caption + hashtags (no #businesstok)
- Cover: frame with the title text clear
- **AI label: ON** · Trial reel: **OFF** · Share to Facebook: **OFF** (Facebook posted separately)
- Topics: Business / Education only if offered, otherwise blank
- Original-audio pop-up → **Share** (not "Turn off and share")
- **Series (Parts):** while posting Part N, Link a reel → Part N-1; then edit Part N-1 → Link a reel → Part N (forward link). Skip if not offered.

## Facebook Reels
- **Switch to the Page first** (not the personal profile)
- + → Reel → **no music / text / filters**
- Caption + hashtags (no #businesstok)
- Audience: **Public** · **AI label: ON** · Trial: **OFF** · Remix: **On** · Topics: blank unless Business/Education
- **Series (Parts):** copy the new Part's link (Share → Copy link), comment it on the previous Part as the Page ("Part N is here 👉 link") and pin that comment.
- **Earn money: ON** (Content Monetization; finish payout setup in Professional dashboard → Monetization)

## YouTube Shorts
- YouTube app → + → Create a Short → **don't trim** (Shorts can be up to 3 min; if it cuts to 1 min, upload from studio.youtube.com)
- Title = caption + hashtags (≤100 characters)
- Public · **Not made for kids** · **Altered/synthetic content (AI use): No** (cartoons; narrator isn't a real person)
- **Related video: the matching full video** (every Short, every time — Parts too; Shorts are not chained to each other)
- Comments: On
