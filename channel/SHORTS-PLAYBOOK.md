## LENGTH RULES (non-negotiable)

- **Default: 25–30 seconds, roughly 70–85 spoken words** at my narration pace (~2.6 words/second; scale word count proportionally for longer cuts).
- Go longer ONLY if the story requires it: **31–40 seconds** when it needs a second twist, a multi-step money mechanism, or a comeback/fraud arc that would feel rushed at 30. **45 seconds is the hard ceiling**, except for a genuinely exceptional story.
- Never pad a simple story to make it longer. The rule is: as short as possible without weakening the story.
- If a story needs more setup, the extra context goes AFTER the stakes, inside the Turn. In a longer cut, only the Turn and Payoff expand — **the stakes deadline never moves** (see skeleton).
- No music. Images change every 2.5–3 seconds.

## SCRIPT TEMPLATE (use this skeleton for every script)

**Format: vertical 1080×1920. One master video for all four platforms.**

- **0:00–0:03 — THE HOOK.** Default: one searchable QUESTION, spoken AND on screen ("Why did ___?" / "How did ___ lose $___?"). Variant (about 3 in 10): a shock STATEMENT when the bare fact beats any question ("Blockbuster could have bought Netflix for $50M"). Same words spoken + shown (SEO). Either form must contain the money mystery. Test: say both versions aloud — whichever stops a stranger mid-scroll wins; if it's close, take the question. No intro, no greeting, no logo.
- **0:03–0:06 — THE SETUP.** One tight line of essential context or surprising origin. The viewer must think "wait, what?" by second 6. Only essential context — anything more goes later, in the Turn.
- **0:06–0:09 — THE STAKES ★.** The concrete money line: the actual dollar figure, scale, or "still selling after ___ years" — fully spoken by 0:09. A money hint in the hook when possible supports this beat but does NOT replace it; a hint is not enough. Never save the stakes for the Payoff. (By 0:12 we are already past my current 9.4-second average watch time.)
- **0:09–0:16 — THE TURN.** "But here's the trick / the catch / where it went wrong…" — the mechanism starts. One idea per line. Pauses between lines ≈ 0.2s — never let the energy dip. Any extra setup/context the story needs goes here.
- **0:16–0:25 — THE PAYOFF.** The full money mechanic: how they actually make / made / lost the money. End on the sharpest verified fact.
- **0:25–0:30 — THE PERFECT-LOOP ENDING.** The final spoken line is a bridge back into the hook, over a visual that matches the opening frame. It can be a causal or unfinished line the hook completes, or a question only when the hook directly answers it without a hard stop.

**THE FORMULA IN ONE LINE:** Hook line (0–3s) → essential setup (3–6s) → concrete money stakes fully spoken by 9s → the turn (9–16s) → the payoff (16–25s) → perfect-loop bridge back into the hook (25–30s), looping forever.

### LOOP RULES (every video, no exceptions)
1. **First frame = last frame.** Same scene, same composition (reuse image 1 for the final shot). The restart must be invisible.
2. **Circular writing:** the last spoken line must flow into the hook — the hook should feel like the answer or the continuation on rewatch. **Seam test:** read the last line and the first line back-to-back; together they should sound like one continuous thought, with no closing full stop in the narration.
3. **Perfect loop comes first.** Do NOT force a standalone viewer question into the narration if it creates a full stop before the restart. The debate question goes in the caption/pinned comment, or as small on-screen text — unless it preserves the seam.
4. **No endings that announce themselves:** no fade-out, no end card, no logo outro, no "SUBSCRIBE FOR MORE" banner.
5. **Tight tail:** trim trailing silence to under ~0.3s. No music.
6. **CTA lives on screen only, small, in the final seconds:** "FOLLOW FOR TOMORROW'S STORY" + a second line naming tomorrow's story: "Tomorrow: [next story's hook line]".

### ON-SCREEN & VISUAL RULES
- **Character:** Business Stick — big round white head, thick black outline, white collared shirt, gold tie — on royal blue. Branding text yellow or white only.
- **Captions ON, burned in,** word-for-word with the narration (for silent viewers + SEO).
- **On-screen text = the keywords:** every beat gets a 2–4 word text pop (e.g., NEVER FINISH / PATENTED 1872 / SAME JELLY ×4). The words on screen should be the words people would search.
- **Say it AND show it in the first 3 seconds** — hook words are spoken, captioned, and popped as text simultaneously.
- **Images change every 2.5–3 seconds** (this is the visual cadence — do not hold an image for ~5 seconds).
- No public numbering on shorts (no "Story #23"). Number files internally instead (see file naming).

### RENDER STEPS (free, CPU only)
1. **Word timings:** pip install pocketsphinx. Per Short put the narration (numbers spelled out) in shorts/dayNN/<slug>/assembly/script.txt, copy shorts/day01/<slug>/assembly/align.py, add a SUB dict entry for any word the dictionary lacks (e.g., "pequod": ["pee", "quad"]), run python3 align.py → word_timing.json.
2. **Config:** assembly/config.py with NARR (voiceover length in s), SHOTS = list of (start_time, image_name_or_"hook", motion) (motions: in, out, left, right, up, hold, or a zoom dict), optional SHAKE, and TEXT = list of (t0, t1, [lines], color, y, size) for on-screen text pops. Cut on the first word of each narration beat from word_timing.json. The hook clip is stretched to the first cut.
3. **Render:** python3 shorts/day01/build_short.py <slug> (from the repo root; use --preview for 540p). It burns in word-by-word yellow captions at y=1330, handles year words (e.g., "nineteen seventy one" → 1971), combines the voiceover and writes <slug>.mp4 (1080×1920). ~3–5 minutes (4 in parallel is fine). Move/copy the script to shorts/dayNN/ for new days.
4. **Sending files:** SendUserFile limit 30 MB. If larger, re-encode with ffmpeg -crf 20 -preset slow -c:a copy (~22 MB). Write temp files in the scratchpad, NOT the repo.
5. **Covers:** IG/FB/TikTok cover = chosen image with a 2–3 line title in the lower middle (yellow line 1, white line 2), inside the 3:4 grid crop (y 240–1680), never over faces. YouTube thumbnail = no text. TikTok/Shorts can use the opening frame.
6. No music.

### QA CHECKLIST (things I have already caught — check before showing me)
- Top text must not cover faces, key props, or anything doing the emotion; keep inside y 240–1680 and centered; no emoji in the big hook text unless asked.
- Keep real-world layout right (e.g., the McDonald's machine is BEHIND the counter, staff side). Keep character outfits and recurring people consistent between shots; props and signs must be right (a sign should say OPEN).
- Don't draw misleading outcomes (an unresolved lawsuit → tug-of-war, not a pile of money). Don't claim anything the sources don't; keep honest wording ("As the story goes", "thanks to").
- Check characters for missing parts (a missing foot was fixed). No cones/objects I don't want.
- On-screen numbers/words are drawn by the renderer (so they're spelled right), not by the image model. No logos or brand text in images.
- Every shot must match its narration line. Remove shots I call unnecessary (e.g., a 1-second shot) and let the neighbor run longer.
- I may ask for 3 options for a hero shot; show them side by side in one sheet and ask for letters.
